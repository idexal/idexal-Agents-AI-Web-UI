## 🐛 Reporting Bugs

1. Search [existing issues](https://github.com/idexal/agents/issues) & [discussions](https://github.com/idexal/agents/discussions).
2. Use the **Bug** issue template — include repro steps, expected vs actual, environment, and acceptance criteria.
3. Security issues → see [SECURITY.md](SECURITY.md) — **do not file public issues for vulnerabilities**.
